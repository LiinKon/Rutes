# Инструкция для нейросети: перенос сценария в «Развилку»

Ты получишь два файла: эту инструкцию и документ со сценарием настольной ролевой игры (ДнД и т. п.).
Задача — сделать JSON-файл, который пользователь импортирует в «Развилку»: это холст, где сцены — карточки, а ветки сюжета — стрелки между ними.

## Шаг 1. Сначала задай два вопроса и дождись ответа

Не делай JSON, пока пользователь не ответит на оба вопроса:

1. **Как расположить ветки?** Вертикально (сцены идут сверху вниз, руты — колонками рядом) или горизонтально (сцены слева направо, руты — полосами друг под другом).
2. **Какую партию переносить?** Перечисли нумерованным списком все партии из документа (заголовки «Партия N — …»), отметь черновики, и попроси выбрать одну. Если партия одна — назови её и попроси подтвердить.

Переноси **только выбранную партию**. Разделы вроде «Мир и лор» и другие партии не включай.

## Шаг 2. Как устроен документ сценария

| В документе | Что это | Во что превращается |
|---|---|---|
| Заголовок 1 «Партия N — Название» | партия | поле `name` |
| Заголовок 2 «Общая линия» | сцены до развилки | карточки без `group` |
| Заголовок 2 «Рута N — Название» | ветка сюжета | у всех её карточек `"group": "Рута N — Название"` |
| Заголовок 3 | сцена | карточка `card`, заголовок → `title` |
| Строка «Тип: …» | тип сцены | `kind` (таблица ниже); строку «Тип» в текст не переносить |
| Обычный абзац | текст рассказчика | в `text` карточки как есть |
| «Имя: реплика» | реплика персонажа | в `text` как `🗣 Имя: «реплика»` |
| «ДМ: …» | заметка для ДМа | в `text` как `▸ ДМ: …` |
| «Проверка: …» | проверка или спасбросок | в `text` отдельным абзацем как `🎲 …` — программа сама вынесет её блоком на поля и проведёт стрелку к этому абзацу |
| «Механика: …» | атаки, способности | в `text` как `◆ …` |
| Текст в скобках «(…)» | описание сцены, ремарка | в `text` как есть, в скобках |
| «Важно: …» | предупреждение | отдельный блок `callout`, `variant: "warn"`, `attach` к сцене |
| «Зачитать игрокам — …:» и текст под ним | текст для игроков | отдельный блок `callout`, `variant: "read"`, `attach` к сцене |
| Список «Переходы:» с пунктами «условие → цель» | стрелки | `edges`: `label` — условие, `to` — цель |
| Раздел «Персонажи партии» | персонажи, стат-блоки | `note` на каждого персонажа, `attach` — к первой сцене из строки «Появляется» |
| Раздел «Награды» | награды по рутам | `note` на каждую руту, `attach` — к концовке этой руты |
| Раздел «Зацепки на будущее» и прочее без сцены | — | `note` без `attach` |

**Тип сцены → kind:** сцена → `scene`; развилка → `choice`; бой → `combat`; диалог → `dialog`; проверка → `check`; награда → `loot`; концовка → `ending`. Уточнения в скобках («бой (необязательный)») игнорируй.

**Цель перехода:**
- название сцены → id этой сцены;
- «Рута N — Название» → id первой сцены этой руты;
- «Рута N — «Сцена»» → id указанной сцены в этой руте;
- уточнения в скобках после цели — добавь к `label`.

### Проверки и спасброски

- Каждая проверка — **отдельный абзац** в тексте сцены, ровно в том месте, где её нужно кидать, и начинается с `🎲` (спасбросок можно с `⚡`).
- Всё о проверке — в одном абзаце: навык или характеристика, СЛ, что будет при успехе и провале. Пример: `🎲 Восприятие СЛ 13 — успех: замечают следы; провал: идут дальше вслепую.`
- **Не делай** для проверок отдельные блоки и стрелки — при импорте программа сама вынесет каждую проверку на поля слева от сцены со стрелкой в нужный абзац. Если пользователь попросит этого не делать — добавь в JSON `"checksAside": false`.

### Главное правило

**Текст сцен переноси полностью, без сокращений и пересказа**, в том порядке, как в документе. Абзацы внутри `text` разделяй пустой строкой (`\n\n`). Не добавляй ничего, чего нет в документе.

## Шаг 3. Формат ответа

Ответь **только JSON в одном блоке кода**:

```json
{
  "app": "razvilka",
  "kind": "board",
  "version": 1,
  "name": "Партия 1 — Название",
  "layout": "vertical",
  "cardWidth": 400,
  "groups": [
    { "name": "Рута 1 — Бой", "color": "red" },
    { "name": "Рута 2 — Сделка", "color": "blue" }
  ],
  "items": [
    { "id": "s1", "type": "card", "kind": "scene", "title": "Таверна", "text": "Текст рассказчика.\n\n🗣 Борк: «Помогите нам.»\n\n▸ ДМ: Борк что-то скрывает." },
    { "id": "s2", "type": "card", "kind": "choice", "title": "Развилка", "text": "…" },
    { "id": "r1", "type": "card", "kind": "combat", "title": "Бой", "text": "…\n\n◆ Утопленник ×3 — КД 10, ХП 16.", "group": "Рута 1 — Бой" },
    { "id": "r2", "type": "card", "kind": "dialog", "title": "Торг", "text": "…\n\n🎲 Убеждение СЛ 14.", "group": "Рута 2 — Сделка" },
    { "id": "w1", "type": "callout", "variant": "warn", "text": "Корабль придёт через 2 ночи.", "attach": "s1" },
    { "id": "c1", "type": "callout", "variant": "read", "text": "Последняя запись в журнале\n\n«Она снова пела…»", "attach": "s2" },
    { "id": "n1", "type": "note", "text": "МЭРРОУ — СИРЕНА\n\nКД 13 · ХП 60", "attach": "r1" }
  ],
  "edges": [
    { "from": "s1", "to": "s2", "label": "игроки соглашаются" },
    { "from": "s2", "to": "r1", "label": "атакуют" },
    { "from": "s2", "to": "r2", "label": "заговаривают" },
    { "from": "r2", "to": "r1", "label": "провал на 5 и больше" }
  ]
}
```

Правила:
- `layout`: `"vertical"` или `"horizontal"` — по ответу на первый вопрос. Для вертикального добавь `"cardWidth": 400`.
- `id` — уникальные, латиница и цифры.
- **Не указывай координаты x, y и размеры** — программа расставит всё сама.
- Порядок `items` — как в документе.
- Цвета рут в `groups`: red, blue, green, yellow, purple, orange, pink, gray.
- Внутри строк JSON кавычки «ёлочки» оставляй как есть, а прямые двойные кавычки экранируй: `\"`.

## Проверка перед ответом

- Все `from`, `to` и `attach` ссылаются на существующие id.
- Каждый пункт из списков «Переходы» стал стрелкой.
- У карточек `choice` не меньше двух исходящих стрелок, у `ending` — ни одной.
- Ни один абзац сцены не потерян и не сокращён.
- JSON валиден: двойные кавычки, без запятых в конце списков.

Если ответ не помещается целиком, скажи об этом пользователю и предложи разбить партию на две части (общая линия + руты отдельными досками) — не обрывай JSON на середине.

После JSON одной строкой напомни: сохранить ответ в файл с расширением `.json` и загрузить в «Развилке» через боковую панель → «Импорт из файла».
