Дважды кликните по пустому месту, чтобы что-нибудь добавить.
Ссылку на картинку можно просто вставить: Ctrl+V.

Кампания
Управление
  • Двойной клик по пустому месту — меню вставки
  • Ctrl+V ссылки на картинку — картинка на холсте
  • Двойной клик по блоку — писать текст, Esc — закончить
  • Кружок справа у блока — протянуть переход; отпустить на пустом месте — новая сцена
  • Уголок у блока — размер; у зоны тянутся все стороны и углы
  • Зона двигается за ярлык и везёт всё, что внутри
  • Зажатая ПКМ или Shift + тянуть — выделить рамкой
  • Колесо — масштаб, Shift + колесо — прокрутка вверх/вниз, тянуть фон или зажатое колесо — перемещение
  • Alt+C — центрировать в зоне/блоке, Alt+H / Alt+V — по горизонтали / вертикали
  • C сцена · T текст · N заметка · R ремарка · K проверка · Z зона · I картинка
  • Проверки на полях: протяните стрелку от блока к сцене и отпустите на нужном абзаце — стрелка укажет, в какой момент кидать. Кнопка 🎲 внизу выносит все проверки выделенной сцены сама
  • Ctrl+C / Ctrl+X / Ctrl+V — копировать, вырезать, вставить блоки (со стрелками между ними, можно на другую доску)
  • Del удалить · Ctrl+D дублировать · Ctrl+F поиск
  • Ctrl+Z отменить · Ctrl+Shift+Z повторить
  • Спойлер: кнопка с перечёркнутым глазом внизу — блок размоется для игроков; «Показать» на плашке — открыть; H — снова скрыть все открытые
  • Двойной тап по пустому месту — добавить текст, заметку или ремарку
  • Двойной тап по блоку — писать текст
  • Тап по блоку — шрифт, размер, цвет, выравнивание внизу
  • Тянуть блок — переместить, тянуть фон — сдвинуть холст
  • Два пальца — масштаб
  • Спойлер: выделите блок → перечёркнутый глаз внизу; «Показать» на плашке — открыть
