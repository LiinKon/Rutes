# Развилка — холст для ветвящихся сценариев

**🔗 Открыть: [liinkon.github.io/Rutes](https://liinkon.github.io/Rutes/)**

Бесконечный холст для подготовки партий ДнД: сцены, развилки, переходы с условиями, ремарки, заметки, зоны-выделения и картинки по ссылке. Это статический сайт без сборки и зависимостей, поэтому его можно просто выложить на GitHub Pages.
Программа не кэшируется: при каждом открытии грузится свежая версия с GitHub, поэтому нужен интернет. Доски при этом хранятся в браузере и никуда не пропадают.

## Где хранятся данные

- Всё сохраняется **в браузере на этом устройстве** (IndexedDB), автоматически, примерно через 0,3 с после каждого изменения. Состояние видно справа на верхней панели («Сохранено»).
- Если браузер вылетит или зависнет, потеряется максимум последнее мгновение работы.
- Данные **не** синхронизируются между устройствами. Для переноса и бэкапа используйте в боковой панели «Экспорт всего (.json)» и «Импорт из файла». При импорте ничего не затирается: всё добавляется отдельной папкой.
- Очистка данных сайта в браузере удалит доски. Делайте экспорт время от времени.

## Проверки на полях

Проверки и спасброски можно вынести блоками слева от сцены со стрелкой, которая указывает в абзац, где их кидать:
- при импорте это делается само для всех абзацев, начинающихся с 🎲 или ⚡;
- для готовой сцены — выделите её и нажмите 🎲 на нижней панели;
- вручную — создайте блок «Проверка» (клавиша K или меню вставки), протяните стрелку от его кружка к сцене и отпустите **на нужном абзаце**.

Стрелка привязана к началу абзаца и не съедет, если текст выше изменится. В Word такие проверки не дублируются.

## Экспорт в Word

Боковая панель → «Текущая доска → Word (.docx)» (или «⋯» у доски → «Экспорт в Word»). Получается обычный документ: общая линия и каждая рута — разделами, сцены — в порядке стрелок, ветка за веткой; реплики, заметки ДМ, проверки, механика и блоки-новеллы — цветными плашками; ремарки и заметки с холста — под своей сценой; у развилок — список «Переходы» с условиями.

## Перенос сценария через нейросеть

1. В боковой панели нажмите «Инструкция для нейросети (.md)».
2. Отдайте любой нейросети этот файл и документ сценария (.docx, .pdf или текст).
3. Нейросеть спросит, как расположить ветки (горизонтально или вертикально) и какую партию переносить, а потом выдаст JSON.
4. Сохраните ответ в файл `.json` (можно целиком, с пояснениями вокруг — лишнее отбросится) и загрузите через «Импорт из файла».
5. Карточки, руты-зоны, ремарки и заметки расставятся автоматически.

Текст инструкции лежит в `ai-guide.js` — его можно править под свой формат документов.

## Управление (ПК)

| Действие | Как |
|---|---|
| Меню вставки | двойной клик по пустому месту или «+» на панели |
| Картинка | Ctrl+V ссылки на изображение, «Копировать изображение» на сайте → Ctrl+V или перетащить картинку из другой вкладки |
| Редактировать текст | двойной клик по блоку или клик по уже выделенному; Enter в заголовке переводит к описанию, Esc завершает |
| Переход | тянуть за кружок справа у блока; если отпустить на пустом месте, появится новая сцена |
| Размер | уголок справа снизу у выделенного блока; у картинки Shift снимает фиксацию пропорций; у зоны тянутся все стороны и углы |
| Зона | двигается за ярлык и тащит за собой всё, что лежит внутри неё целиком |
| Выделить несколько | зажатая ПКМ, Shift + тянуть по пустому месту, Shift + клик или кнопка «рамка» |
| Выравнивание | кнопка ⊞ на нижней панели; Alt+C центрировать, Alt+H / Alt+V по горизонтали / вертикали. Один блок выравнивается внутри зоны или блока, в котором лежит; несколько — относительно того, кто их вмещает, или друг друга |
| Масштаб / сдвиг | колесо мыши, тянуть фон (или зажать колесо) |
| Клавиши | C сцена, T текст, N заметка, R ремарка, Z зона, I картинка, Del удалить, Ctrl+D дублировать, Ctrl+Z отменить, Ctrl+Shift+Z повторить, Ctrl+F поиск |
