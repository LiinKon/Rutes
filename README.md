# Развилка — холст для ветвящихся сценариев

Бесконечный холст для подготовки партий ДнД: сцены, развилки, переходы с условиями, ремарки, заметки, зоны-выделения и картинки по ссылке. Это статический сайт без сборки и зависимостей, поэтому его можно просто выложить на GitHub Pages.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `razvilka`.
2. Загрузите в него все файлы из этой папки: **Add file → Upload files**, перетащить всё, **Commit**.
3. Откройте **Settings → Pages**, в **Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://<ваш-логин>.github.io/razvilka/`.

На телефоне откройте эту ссылку и выберите в меню браузера «Добавить на главный экран». После этого приложение запускается как отдельное и работает без интернета. Картинки по ссылкам без интернета не загрузятся.

## Где хранятся данные

- Всё сохраняется **в браузере на этом устройстве** (IndexedDB), автоматически, примерно через 0,3 с после каждого изменения. Состояние видно справа на верхней панели («Сохранено»).
- Если браузер вылетит или зависнет, потеряется максимум последнее мгновение работы.
- Данные **не** синхронизируются между устройствами. Для переноса и бэкапа используйте в боковой панели «Экспорт всего (.json)» и «Импорт из файла». При импорте ничего не затирается: всё добавляется отдельной папкой.
- Очистка данных сайта в браузере удалит доски. Делайте экспорт время от времени.

## Управление (ПК)

| Действие | Как |
|---|---|
| Меню вставки | двойной клик по пустому месту или «+» на панели |
| Картинка | Ctrl+V ссылки на изображение, «Копировать изображение» на сайте → Ctrl+V или перетащить картинку из другой вкладки |
| Редактировать текст | двойной клик по блоку; Enter в заголовке переводит к описанию, Esc завершает |
| Переход | тянуть за кружок справа у блока; если отпустить на пустом месте, появится новая сцена |
| Размер | уголок справа снизу у выделенного блока; у картинки Shift снимает фиксацию пропорций |
| Зона | двигается за ярлык и тащит за собой всё, что лежит внутри неё целиком |
| Выделить несколько | Shift + тянуть по пустому месту, Shift + клик или кнопка «рамка» |
| Масштаб / сдвиг | колесо мыши, тянуть фон (или зажать колесо) |
| Клавиши | C сцена, T текст, N заметка, R ремарка, Z зона, I картинка, Del удалить, Ctrl+D дублировать, Ctrl+Z / Ctrl+Y, Ctrl+F поиск |

## Телефон

Упрощённый режим: просмотр, масштаб щипком, добавление текста, заметок и ремарок, редактирование текста (двойной тап), шрифт, размер, жирный/курсив/подчёркнутый, цвет текста, выравнивание и перемещение текстовых блоков. Переходы, зоны и картинки на телефоне видны, но меняются только на ПК.

## Файлы

- `index.html`, `style.css`, `app.js` — само приложение
- `sw.js`, `manifest.webmanifest`, `icon*` — работа без интернета и установка на телефон
