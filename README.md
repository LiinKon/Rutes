# 🗺️ Развилка

### **[▶ Открыть Развилку — liinkon.github.io/Rutes](https://liinkon.github.io/Rutes/)**

**Бесконечный холст для подготовки партий в ДнД и других настольных ролевых играх.** Сцены — карточками, развилки сюжета — стрелками с условиями, руты — цветными зонами. Вся партия видна целиком: где игроки могут свернуть, где кидать проверки и что их ждёт в конце каждой ветки.

Работает в браузере на ПК и телефоне, а для Windows есть отдельное приложение. Регистрация не нужна, данные никуда не отправляются.


---

## Что умеет

**Сценарий**
- **Сцены-карточки** семи типов: сцена, выбор, бой, диалог, проверка, награда, концовка — у каждого свой цвет.
- **Переходы-стрелки** с подписью-условием («провалили проверку», «атакуют»). Протянул стрелку на пустое место — сразу создалась новая сцена.
- **Зоны-выделения** для рут, как маркером в тетради. Зона перетаскивается вместе со всем, что в ней лежит.
- **Ремарки:** «Ремарка ДМ», «Зачитать игрокам», «Важно», «Проверка», а также заметки-стикеры и свободный текст.
- **Проверки на полях:** спасброски и проверки стоят слева от сцены, а пунктирная стрелка указывает ровно в абзац, где их кидать.

- **Спойлеры:** любой блок можно размыть «матовым стеклом», чтобы игроки не увидели его раньше времени. Открывается одним нажатием, клавиша **H** снова прячет всё.
- **Картинки по ссылке:** достаточно вставить адрес картинки через Ctrl+V. С Пинтереста, Гугла и других сайтов — «Копировать адрес изображения».

**Работа с текстом**
- Текст пишется прямо на холсте. Шрифт, размер, жирный, курсив, подчёркивание, цвет и выравнивание.
- Копировать, вырезать и вставлять блоки — со всеми стрелками между ними, в том числе на другую доску.
- Выравнивание и центровка внутри зоны или карточки, поиск по доске, отмена и повтор.

**Организация**
- **Папки и доски** — например, папка на каждую партию, внутри «Сценарий» и «Карта связей».
- **Светлая и тёмная тема** и **свой акцентный цвет**.
- Отдельное окно без панелей браузера — удобно держать рядом с Foundry или Roll20.

**Импорт и экспорт**
- **Экспорт в Word (.docx):** руты — разделами, сцены — по порядку стрелок, реплики, проверки и заметки ДМа — цветными плашками.
- **Перенос сценария через нейросеть:** отдаёте любой нейросети встроенную инструкцию и свой документ — она соберёт файл, который импортируется в готовую схему с рутами, проверками на полях и заметками.
- Экспорт и импорт всей кампании одним файлом — для бэкапа и переноса между устройствами.

## Как начать

| | |
|---|---|
| 🌐 **В браузере** | Откройте **[liinkon.github.io/Rutes](https://liinkon.github.io/Rutes/)**. При первом запуске там будет пример доски. |
| 📱 **На телефоне** | Откройте ту же ссылку, в меню браузера — «Добавить на главный экран». На телефоне доступны просмотр, текст, заметки и ремарки. |
| 💻 **Приложение для Windows** | **[Releases](https://github.com/LiinKon/Rutes/releases/latest)** → скачайте `Razvilka-setup-….exe` и установите. Права администратора не нужны. |

> Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Программа просто не подписана платным сертификатом.

**Быстрый старт:** двойной клик по пустому месту → выберите, что добавить → пишите. Подсказки по всем клавишам — кнопка **i** справа внизу.

## Где хранятся данные

- **Сайт:** доски хранятся в браузере на вашем устройстве и сохраняются автоматически после каждого изменения. Наведите на «Сохранено» вверху — там подробности.
- **Приложение для ПК:** то же самое, плюс **автоматические резервные копии** всей кампании в выбранную папку: последняя копия и копии за 14 дней. Если выбрать папку в Яндекс.Диске, OneDrive или Google Drive, копии ещё и уедут в облако.
- На сервер ничего не отправляется. Другие устройства ваших досок не видят — переносите через «Экспорт всего» → «Импорт из файла».
- Очистка данных сайта в браузере удалит доски, поэтому время от времени делайте экспорт.

## Перенос готового сценария через нейросеть

1. Боковая панель → **«Инструкция для нейросети (.md)»**.
2. Отдайте любой нейросети этот файл и свой сценарий (.docx, .pdf или текст).
3. Она спросит, как расположить ветки (вертикально или горизонтально) и какую партию переносить, а потом выдаст JSON.
4. Сохраните ответ в файл `.json` и загрузите через **«Импорт из файла»**. Сцены, руты-зоны, проверки на полях и заметки расставятся сами.

## Управление (ПК)

| Действие | Как |
|---|---|
| Добавить блок | двойной клик по пустому месту или «+» на панели |
| Писать текст | двойной клик по блоку или клик по уже выделенному; Esc — закончить |
| Переход | тянуть за кружок справа у блока; отпустить на пустом месте — новая сцена |
| Проверка на полях | стрелку от блока «Проверка» отпустить на нужном абзаце сцены; кнопка 🎲 — вынести все проверки сцены |
| Спойлер | перечёркнутый глаз на нижней панели; **H** — скрыть все открытые |
| Выделить несколько | зажатая ПКМ или Shift + тянуть |
| Масштаб / прокрутка | колесо — масштаб, Shift + колесо — вверх/вниз, тянуть фон или зажатое колесо — перемещение |
| Клавиши | **C** сцена · **T** текст · **N** заметка · **R** ремарка · **K** проверка · **Z** зона · **I** картинка |
| Правка | **Ctrl+C / X / V** · **Ctrl+D** дублировать · **Del** удалить · **Ctrl+Z / Ctrl+Shift+Z** · **Ctrl+F** поиск |
| Выравнивание | **Alt+C** центрировать · **Alt+H / Alt+V** по горизонтали / вертикали |

## Для разработчика

- Сайт — обычные статические файлы в корне (`index.html`, `app.js`, `style.css`, `ai-guide.js`), без сборки и зависимостей. Публикуется через GitHub Pages из ветки `main`, папка `/ (root)`.
- Приложение для ПК — папка `desktop/` (Tauri 2). Интерфейс оно берёт из тех же файлов сайта.
- **Новая версия приложения:** поднять `version` в `desktop/src-tauri/tauri.conf.json` и `APP_VERSION` в `app.js` → вкладка **Actions** → «Сборка приложения для ПК» → **Run workflow**. Через 10–15 минут установщик появится в Releases. Установка новой версии поверх старой сохраняет доски.
- Текст инструкции для нейросети — в `ai-guide.js`.
