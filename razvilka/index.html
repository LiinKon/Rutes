Дважды кликните по пустому месту, чтобы что-нибудь добавить.
Ссылку на картинку можно просто вставить: Ctrl+V.

Кампания
Управление
  • Двойной клик по пустому месту — меню вставки
  • Ctrl+V ссылки на картинку — картинка на холсте
  • Двойной клик по блоку — редактировать текст
  • Кружок справа у блока — протянуть переход; отпустить на пустом месте — новая сцена
  • Уголок справа снизу — размер
  • Зона двигается за ярлык и тянет за собой всё, что внутри
  • Колесо / щипок — масштаб, тянуть фон — перемещение
  • Shift + тянуть — выделить рамкой
  • Клавиши: C сцена, T текст, N заметка, R ремарка, Z зона, I картинка, Del удалить, Ctrl+D дублировать, Ctrl+Z / Y
